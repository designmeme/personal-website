# 이력서 인쇄 스타일 개선 설계

## 목표

`/about/resume/` 페이지를 브라우저에서 인쇄하거나 PDF로 저장할 때
사이트 UI를 제외한 이력서 본문이 A4 문서로 깔끔하게 출력되도록 한다.
화면용 레이아웃과 다른 페이지의 인쇄 결과는 변경하지 않는다.

## 접근 방식

이력서 페이지의 콘텐츠에 전용 식별 클래스를 추가하고, 전역 스타일시트의
`@media print` 안에서 해당 클래스가 있는 페이지에만 인쇄 규칙을 적용한다.
별도 PDF 페이지나 중복 마크업은 만들지 않는다.

## 인쇄 레이아웃

- 용지는 A4 세로 방향으로 지정한다.
- 페이지 여백은 약 15mm로 설정해 긴 경력기술서의 가용 폭을 확보한다.
- 사이트 공통 헤더와 푸터, 페이지 제목 및 수정일 영역은 숨긴다.
- `프론트엔드 개발자 이지혜`부터 마지막 남김글까지 출력한다.
- 화면 레이아웃의 바깥 여백과 최대 너비를 제거하고 인쇄 가능 폭을 사용한다.
- 배경은 흰색, 본문과 제목은 검정 계열로 고정해 테마에 영향받지 않게 한다.
- 색상 및 그림자처럼 종이에 불필요한 장식은 제거한다.

## 페이지 분할

- 제목은 바로 다음 콘텐츠와 같은 페이지에 남도록 한다.
- 경력 및 프로젝트의 개별 항목은 가능한 한 항목 내부에서 나뉘지 않게 한다.
- 목록 전체처럼 큰 컨테이너에는 분할 방지를 적용하지 않아 빈 공간이나
  예상치 못한 대규모 이동이 생기지 않도록 한다.
- 구분선과 다음 제목이 서로 다른 페이지에 홀로 남지 않도록 처리한다.

## 링크 표현

- 연락처의 LinkedIn과 GitHub 링크는 링크명과 실제 URL을 함께 출력한다.
- 프로젝트 URL은 현재 표시 문자열을 유지하며 브라우저가 URL을 한 번 더
  자동 삽입하지 않도록 한다.
- 긴 URL은 인쇄 영역 밖으로 넘치지 않게 줄바꿈을 허용한다.

## 검증 기준

- 기존에 실행 중인 `localhost:8001` 개발 서버를 사용하며 재시작하지 않는다.
- 타입 검사를 통과해야 한다.
- Chrome 인쇄 미리보기에서 헤더·푸터·페이지 메타가 보이지 않아야 한다.
- A4 각 페이지에서 콘텐츠가 잘리거나 가로로 넘치지 않아야 한다.
- 제목과 개별 경력/프로젝트 항목의 페이지 분할이 자연스러워야 한다.
- 일반 화면에서 기존 레이아웃과 스타일이 유지되어야 한다.
